# XXD Panel 017 · 韩式稚拙扁平编辑插画

Turn each supplied photograph into finished editorial artwork. Preserve the real photograph only in paired modes; every transformed frame must reinterpret that same source as a light Korean flat editorial illustration with rounded simplified forms, rough jittery and locally broken black outlines, pure flat colour, bright breathing fields, imperfect asymmetry, and typography drawn into the composition.

Operational rules follow the shared XXD Panel workflow contract: four combinable modes; source-adaptive ordinary canvases; exact 50/50 paired geometry; linked or independent four-device wallpapers; copy and locale preflight; fresh generation jobs; privacy-preserving raster generation; and one fresh task directory per source and mode. Style-specific sections may refine aesthetics, copy hierarchy, and acceptance criteria but never override this contract.

## Non-negotiable contract

- One source photo may be processed in one or more selected modes. Each selected ordinary mode (`top-bottom`, `left-right`, `design-only`) produces one PNG; selected `wallpaper-pack` produces exactly four separate PNGs. Selecting all four modes therefore produces seven final files per source. Keep every mode in its own task directory and never combine modes, sources, or wallpapers into a grid, contact sheet, or overview.
- Resolve a non-empty ordered set of modes before generation: `top-bottom`, `left-right`, `design-only`, and/or `wallpaper-pack`. Accept one choice, multiple choices separated by `+`, Chinese/English commas or whitespace, natural-language names, or `全部` / `all`. Deduplicate repeated choices and execute in menu order 1→4. If none is specified, ask with the multiline multi-select menu in the workflow. Do not ask again when the set is already clear.
- When the selected set contains `wallpaper-pack`, require a second choice: `linked` or `independent`. A linked pack approves one anchor wallpaper, iPad by default, and makes every other device reference both the original photo and that same anchor. An independent pack gives every device only the original photo. Neither permits resizing or cropping one wallpaper into the others. Do not ask this follow-up when wallpaper mode is not selected.
- Paired modes split exactly 50/50. `design-only` and every wallpaper contain no visible source photograph, no seam, and no reserved photographic panel.
- Exact user pixels have highest priority, followed by an explicit ratio or destination. Otherwise ordinary modes adapt to the complete source: `top-bottom` = `W×2H`, `left-right` = `2W×H`, and `design-only` = `W×H`. Never impose the archived initial brief's 3:4 canvas as a silent default.
- Visible photography remains faithful. Allow only restrained editorial grading and environmental extension needed for an explicitly overridden canvas. Never stretch, distort, repaint, replace, or structurally alter the subject.
- The transformed frame must preserve the source layout, object relations, core action, and at least three identity cues while converting them into a light, naive Korean flat editorial illustration. It is not tracing, photo cartoonisation, vintage mixed media, a generic children's cartoon, commercial sticker art, photoreal painting, 3D rendering, or unrelated decoration.
- Copy has no silent default. Resolve automatic copy, exact custom copy, or text-free output before image generation. Automatic and custom modes also require a target language or locale. By default, one source-specific copy package is shared verbatim across all selected modes; explicit per-mode copy instructions override it.
- Render no logo, watermark, signature, colour swatch, UI, device mockup, decorative pseudo-text, or unrelated explanatory prose.

## Aesthetic motive lock

Modes and device ratios may change placement and aspect ratio but never the 017 motive. Every transformed frame must visibly express this chain:

**this exact photographed subject or inseparable relationship → preserve the approximate layout, object relations, core action, and at least three identity cues → simplify into rounded, slightly exaggerated geometric forms → use rough jittery, locally broken black hand-drawn outlines with pure flat fills → organise one clear visual centre through scale difference, offset, occlusion, light crop, bright colour fields, whitespace, and imperfect asymmetry → integrate one short handwritten title plus a few restrained micro-notes along contour, colour-block edge, whitespace, or axis**.

Playfulness comes from source-bound proportion, placement, action, and editorial timing—not stock cute faces, mascots, stickers, or unrelated props. Korean editorial illustration and carefully designed picture books are construction influences rather than templates.

Reject the result as generic when an unrelated photo could replace the source without materially changing layout, silhouette, gesture, relation, palette areas, or copy. Also reject vintage paper wash, watercolor, gouache depth, pencil or pastel texture, thin elegant linework, smooth vector polish, uniform comic outlines, kawaii stickers, gradients, shadows, dirty greys, complex mixing, photoreal shading, 3D volume, plastic surfaces, dense scenery, or templated children's illustration.

## 017 visual system

### Recognisable flat subject

- Privately lock at least three source-specific cues across contour, pose/orientation, proportion, material, colour, opening, connection, overlap, negative shape, or relationship distance.
- Preserve the source's approximate layout, object relations, and core action. Rebuild each essential subject with rounded, simple, slightly exaggerated geometric forms and a clear centre of gravity; simplification removes realism but never replaces identity.
- People keep pose, direction, clothing mass, and relational distance; animals keep body rhythm and head direction; plants keep growth gesture; architecture keeps skyline and defining openings; objects and vehicles keep functional silhouette and negative shape; landscapes keep one source-specific terrain or spatial relation.
- Keep one principal subject or inseparable relationship as the clear visual centre. Supporting objects may clarify action, scale, setting, or rhythm but never compete with it.

### One centre and playful asymmetry

- Organise one clear centre. Use size difference, offset, overlap, occlusion, light edge crop, and imperfect asymmetry to give supporting objects a lively rhythm.
- Use large bright solid background fields and whitespace to carry the subject. A complete side or local colour block may remain open as breathing space.
- Preserve the source's spatial and narrative relationship without rebuilding realistic perspective or a complex scene.
- Do not fill space with confetti, generic suns, leaves, stars, grids, ornamental squiggles, or a second focal point.

### Rough broken outline and pure flat fill

- Draw contours in black with visible hand pressure: rough, jittery, slightly uneven, and locally broken while preserving readability.
- Fill shapes with clean, opaque, pure flat colour. Keep outline and fill slightly independent where a small human mismatch supports the drawing.
- Remove realistic light, perspective, material detail, texture modelling, cast shadow, and atmospheric depth. Depth comes only from flat overlap, occlusion, scale, and placement.
- Do not imitate watercolor, gouache, coloured pencil, pastel, crayon, dry brush, vintage paper, smooth vectors, uniform comic inking, clay, resin, or plastic CGI.

### Bright source-derived flat colour

- Extract the photograph's most spirited and recognisable colours, then convert them into a limited set of high-value, high-purity flat fields.
- Bright blue, red, yellow, green, and white are possible relationships, never a fixed palette. Preserve source colour identity and establish a strong area contrast between background and subject.
- Variation comes from area proportion, adjacency, overlap, and whitespace—not gradients, transparent washes, texture, or shading.
- Avoid dirty greys, muddy or complex mixtures, a sugary rainbow, corporate brand palettes, uniformly beige desaturation, and colours unsupported by the source.

## Copy and typography belong to 017

017 text behaves like naive but designed Korean-editorial lettering inside the flat illustration—not a generic poster headline, UI label, sticker caption, data wall, or detached digital overlay.

- Automatic copy derives one short title from the subject, action, relation, visible mood, or grounded story, then adds only a few tiny phrases, object words, supplied place words, indexes, or playful notes when useful. It may be warm, friendly, playful, relaxed, or gently strange without inventing biography or facts.
- Prefer one compact title plus zero to two tiny supporting elements. A year appears only when the user supplies it or the source reliably establishes it.
- Preserve exact user wording verbatim. Refine an editable direction only within permission while protecting audience, mandatory terms, tone, and semantic phrase breaks.
- Apply the unrelated-image swap test: generic lifestyle words that survive on another source must be rewritten.

Typography has its own 017 construction:

- **Role:** an illustrated editorial element that completes rhythm, scale, and source meaning.
- **Voice:** bright, friendly, playful, relaxed, slightly awkward, and knowingly designed.
- **Construction:** one compact title with a handwritten feel, uneven weight, or gentle tilt, plus at most two much smaller and clearer supporting elements. Do not force the same proportions onto every script.
- **Placement:** follow a subject contour, colour-block edge, whitespace, or picture axis; allow slight rotation, offset, split, or interlock only when it strengthens composition. Never cover identity cues or scatter words decoratively.
- **Material:** flat black or source-derived colour with subtle hand irregularity, visually belonging to the outline-and-fill system rather than simulating vintage print or dry media.
- **Script:** use a native naive-editorial equivalent for the resolved locale. Preserve natural Chinese, Japanese, Korean, Arabic, and Latin shaping, spacing, orientation, and semantic line breaks.

Resolve locale independently from command language:

```text
target market or audience > requested output language > direction language; if none is explicit, ask before generation
```

Localise by transcreation using native wording, rhetoric, punctuation, spacing, shaping, and semantic line breaks. Never infer nationality or audience language from appearance, clothing, scenery, filenames, metadata, or signs.

      请分别输入手机、iPad、电脑、儿童手表的尺寸

5. Open one fresh job boundary and reserve the next unused sibling output directory for every source and selected mode. Confirm only current user-supplied sources, inspect each separately, and read the full prompt matching the working language:
   - Chinese: [references/xxd-panel-017-prompt.zh-CN.md](references/xxd-panel-017-prompt.zh-CN.md)
   - English: [references/xxd-panel-017-prompt.en.md](references/xxd-panel-017-prompt.en.md)

   Within the same current invocation, ordinary modes may reuse one newly approved transformed intermediate only when frame dimensions, aspect ratio, source facts, aesthetic instructions, typography, and locked copy are identical. ## Composition commands

```bash
# Source-adaptive top-bottom
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout top-bottom

# Source-adaptive left-right
python3 scripts/compose_panel.py --plan --layout left-right --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout left-right

# Design-only
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout design-only

# One wallpaper, repeated separately for all four devices
python3 scripts/compose_panel.py --design phone.png --out wallpaper-phone.png \
  --layout design-only --size 1440x3200
```

`--size WIDTHxHEIGHT` overrides `--canvas` and source adaptation. Generate the design at the exact planned aspect; if exact pixels are unsupported, use a closest supported same-aspect bitmap and resample proportionally without cropping. Audit with the same layout used to build the result.
