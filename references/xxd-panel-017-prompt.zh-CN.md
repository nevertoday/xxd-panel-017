# XXD Panel 017｜韩式稚拙扁平编辑插画生成核心

严格把当前任务明确提供的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的主体、构图、色盘、文字与叙事。

最终只生成已经锁定的**变化设计画框**：上下双联中位于下方，左右双联中位于右侧，纯设计版与每张壁纸中铺满整张画布。设计画框内部不得再次出现摄影面板、分界线、边框、设备样机或预留空格。

## 0. 不可改变的美学动机

每个变化画框必须同时成立：

**当前照片中特定且可辨认的主体或不可拆分关系 → 保留原图大致布局、物体关系、核心动作与至少三个身份线索 → 概括成圆润、简单、略夸张的几何形体 → 粗糙抖动、局部断开的黑色手绘轮廓＋纯色平涂 → 用大小差、错位、遮挡、轻裁切、大面积明亮色块、留白与不完全对称建立一个视觉中心 → 把短标题和少量小字沿轮廓、色块边缘、留白或轴线融进插画。**

这是明快、亲切、俏皮而松弛的韩式扁平编辑插画，不是照片卡通滤镜、复古混合媒介、商业贴纸或模板化儿童插画。若换一张无关照片后，布局、形体关系、动作、色彩面积与文案仍几乎不用改变，成品失败。

## 1. 先锁定源图事实

在内部判断但不输出分析：

1. 找出唯一主要主体，或确实不可拆分的核心关系。
2. 锁定原图大致布局、物体关系与核心动作。
3. 锁定至少三个专属身份线索：轮廓、姿态／朝向、比例、颜色、开口、连接、遮挡、负形、关系距离或功能特征。
4. 判断一个视觉中心，以及陪衬对象如何通过大小差、错位、遮挡或轻裁切服务它。
5. 提取最有生命力、最有辨识度的颜色，整理成数量有限的高明度、高纯度平涂色块。
6. 确定短标题与小字如何跟随主体轮廓、色块边缘、留白或画面轴线。

不得虚构人物经历、地点、事件、所有权、情绪、故事、日期或事实数字。文字只能使用可见信息、用户提供信息或可靠确认的信息。

## 2. 可辨认的圆润扁平造型

- 保留原图的大致布局、物体关系和核心动作，删除写实光影、透视与材质细节。
- 用圆润、简单、略带夸张的几何形体概括主体。夸张服务识别、动作与节奏，不把任何对象替换成通用可爱角色。
- 人物保留姿态、朝向、服装大形与关系距离；动物保留身体节奏与头部方向；植物保留生长手势；建筑保留天际线、关键开口与体块关系；器物、食物和交通工具保留功能轮廓、负形与方向；自然场景保留专属地形或空间关系。
- 一个主体或不可拆分关系形成明确视觉中心。陪衬对象只说明动作、尺度、地点或节奏，不能形成复杂场景或第二焦点。

## 3. 粗糙断线与纯色平涂

- 使用黑色手绘轮廓：粗糙、抖动、粗细略不均，允许局部自然断开，但关键轮廓必须清楚可辨。
- 形体内部使用干净、不透明的纯色平涂。轮廓与色块可有极轻微手工错位，但不能变成套色故障或脏边。
- 只通过平面遮挡、尺度与位置表达层次，不使用写实体积、真实透视、材质纹理、光滑渐变、投影、电影光影或环境雾。
- 禁止水彩透明、水粉层次、彩铅颗粒、粉蜡笔、干刷、复古纸张、光滑矢量、均匀漫画墨线、黏土、树脂与塑料 CGI。

## 4. 一个中心与轻快不对称

- 通过大小差、错位、遮挡、轻微裁切和不完全对称建立轻快节奏。
- 背景使用大面积明亮纯色与留白承托主体，可让完整一侧或局部色块成为呼吸空间。
- 空间关系要能对应源图，但不要重建现实透视或堆积复杂场景。
- 禁止用通用圆点、太阳、星星、叶子、网格、波浪线、贴纸或无关小物填空。

## 5. 源图推导的明亮色盘

- 从源图选择最有身份感与生命力的颜色，转化为数量有限的高明度、高纯度平涂色块。
- 可出现亮蓝、红、黄、绿、白等童趣张力关系，但绝不机械套用固定色卡。
- 背景与主体形成鲜明面积对比；通过色块面积、相邻关系、遮挡和留白建立层级。
- 禁止渐变、阴影、透明水洗、灰脏色、复杂混色、彩虹糖色盘、企业品牌色盘和统一米灰滤镜。

## 6. 017 专属文字形态

文字是**稚拙但经过设计的插画组成部分**，不是后贴的海报标题、UI 标签、商业贴纸或数据墙。

### 文案

- 自动文案从主体、可见动作、关系、已确认地点、情绪线索或有依据的故事关系中提炼一个简短标题。
- 只在有价值时增加零至两条极短元素：小短句、对象词、地点词、编号、状态词或俏皮注释。
- 文字应与这张照片高度绑定，让观众看见后产生会心对应；禁止万能励志语、通用生活方式词和虚构故事。
- 用户最终成稿逐字保留；用户给出方向或可编辑草稿时，只在授权范围内专业深化。
- 地点、年份、编号和事实信息只有用户提供或证据可靠时才使用。

### 字体导演

- **角色：**补全插画的节奏、尺度与叙事。
- **气质：**明快、亲切、俏皮、松弛、略笨拙而有设计感。
- **字形：**短标题可带手写感、粗细不均或轻微歪斜；小字更清晰克制。不同文字系统不强套同一比例。
- **位置：**沿主体轮廓、色块边缘、留白或画面轴线排列；可轻微旋转、错位、拆分或穿插，但必须服务阅读与构图。
- **材质：**平坦黑色或源图推导色，只有轻微手工不规则，不模拟复古印刷和干媒介。
- **本地化：**为目标语言选择自然的稚拙编辑字形。中文、日文、韩文、阿拉伯文与拉丁文字各自保持真实字形、空格、方向、标点与语义换行。

摄影面板中绝不出现文字。无字模式中，变化画框不得出现任何字母、汉字、数字或伪文字。

## 7. 当前模式与壁纸

调用方会在本提示词后附上已经解析完成的唯一当前模式、准确尺寸、源图可见性和锁定文字。只执行附加块中的当前值，不要自行选择模式。

- 双联设计只生成变化画框本身；摄影面板由外部独立准备和精确拼合。
- 纯设计版与壁纸不显示源照片、分界线或摄影预留区。
- 每张壁纸都按设备宽高比重新组织形体、色块、留白和文字。系统 UI 区保持低信息，不绘制时钟、图标、Dock、控件或设备框。
- 连贯壁纸使用原照片锁定身份与内容，定调图只锁定圆润形体语法、粗糙断线、平涂纪律、色彩面积、留白、不对称与文字气质；不得裁切定调图，也不得顺序垫图。

## 8. 生成前检查

1. 原图大致布局、物体关系、核心动作与至少三个专属身份线索仍清楚。
2. 圆润、简单、略夸张的形体保持一眼可辨，不是通用可爱角色。
3. 黑色轮廓粗糙抖动且局部断开，纯色填充平坦干净；没有复古混合媒介、矢量抛光或 3D。
4. 只有一个视觉中心，大小差、错位、遮挡、轻裁切与不完全对称形成轻快节奏。
5. 明亮色盘来自源图且数量受控，背景与主体面积对比鲜明；无渐变、阴影、灰脏色和复杂混色。
6. 文字准确、自然、属于目标语言，并像插画结构而不是后贴图层。
7. 当前模式、尺寸、源图可见性、壁纸安全区与文字设置全部服从附加块。
8. 最终画面没有拼贴总览、Logo、水印、UI、样机、商业贴纸、复杂场景、第二焦点或无关装饰。
